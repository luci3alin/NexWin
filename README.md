- **Optimizator Spotify SpotX Nativ**: Asistent în 4 pași pentru blocarea reclamelor audio/banner, eliminarea telemetriei și selector de teme (Dracula, Nord, Catppuccin).

- **Modal Redesenat de Oprire Procese**: Dialog nou de confirmare cu stil cyber navy și insignă de pericol.
- **Reactivitate Startup Manager**: Comutare instantanee a comutatoarelor și actualizare a contoarelor în timp real.
- **Stabilitate Live Wallpaper pe Windows LTSC**: Flag-uri keepalive împotriva suspendării Chromium și watchdog Explorer.
- **Jurnal Operații Îmbogățit**: Log-uri complete de diagnostic la adăugarea, aplicarea, comutarea și ștergerea videoclipurilor.
