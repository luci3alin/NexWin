# NexWin v1.0.92 - Windows 11 Tuning & Gaming Suite

**NexWin** este o suită nativă dedicată optimizării sistemului Windows 10/11, reducerii latenței în jocuri (NVIDIA Profile Inspector Suite, HAGS, TCP NoDelay), gestionării complete a driverelor și curățării avansate.

### Ce include versiunea v1.0.92:
- **Corectare Vizibilitate Live Wallpaper (Stratul WorkerW)**: Fereastra video se atașează direct ca și copil în stratul WorkerW din Explorer, eliminând problema de obstrucționare cauzată de wallpaper-ul static de Windows.
- **Detecție și Sincronizare Desktop Multi-Monitor**: Aliniere precisă a ferestrei video pe întregul desktop virtual (virtual screen bounds).
- **Mecanism de Rezervă Windows 11 24H2**: Fallback automat pe Progman cu suprimarea oricărei ferestre WorkerW care blochează ecranul.
- **Restaurare Curată a Desktopului**: Curățarea tuturor instanțelor orfane din Progman și WorkerW la oprirea sau schimbarea fundalurilor video.
- **Toate Noutățile din v1.0.91**: Asistentul Spotify SpotX cu teme, vizualizarea WinDirStat pentru stocare, sortare dinamică de coloane și jurnal detaliat de operații.
